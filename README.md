# Парсер документации Python и PEP

Проект представляет собой консольное приложение на Python для сбора информации с официальных сайтов документации Python и Python Enhancement Proposals (PEP).

Парсер получает HTML-страницы, извлекает данные с помощью BeautifulSoup и выводит результаты в терминал или сохраняет их в CSV-файлы.

## Режимы работы

- **`whats-new`** — собирает ссылки на статьи о нововведениях в версиях Python, их заголовки и информацию об авторах и редакторах.
- **`latest-versions`** — собирает информацию о версиях Python, ссылках на документацию и статусах версий.
- **`download`** — скачивает ZIP-архив HTML-документации актуальной версии Python с официального сайта.
- **`pep`** — собирает статистику статусов документов PEP.

В режиме `pep` парсер:

1. Получает список PEP с главной страницы https://peps.python.org/.
2. Последовательно переходит на страницы документов, исключая PEP 0.
3. Извлекает фактический статус каждого PEP.
4. Сравнивает статус документа со статусом, указанным в общем списке.
5. Записывает обнаруженные несовпадения в лог.
6. Подсчитывает количество PEP для каждого фактического статуса.
7. Формирует итоговую таблицу статистики.

## Версия Python

- Python 3.12

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/VirentLilium/bs4_parser_pep.git
cd bs4_parser_pep
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация на Windows в Git Bash:

```bash
source venv/Scripts/activate
```

Активация на Linux/macOS:

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install --upgrade pip
```

```bash
python -m pip install -r requirements.txt
```

### 4. Просмотр справки

```bash
python -m src.main -h
```

**Приложение следует запускать как Python-модуль:**

```bash
python -m src.main
```

Запуск через `python src/main.py` из корня проекта может привести к ошибке `ModuleNotFoundError: No module named 'src'`!

## Режимы работы

### 1. Нововведения Python — `whats-new`

```bash
python -m src.main whats-new
```

Источник: https://docs.python.org/3/whatsnew/

Собирает ссылки на статьи, заголовки и сведения об авторах и редакторах.

### 2. Версии Python — `latest-versions`

```bash
python -m src.main latest-versions
```

Источник: https://docs.python.org/3/

Собирает ссылки на документацию Python, версии и их статусы.

### 3. Скачивание документации — `download`

```bash
python -m src.main download
```

Источник: https://docs.python.org/3/download.html

Скачивает ZIP-архив HTML-документации актуальной версии Python с официального сайта и сохраняет его в директорию:

```text
src/downloads/
```

### 4. Статистика PEP — `pep`

```bash
python -m src.main pep
```

Источник: https://peps.python.org/

Парсер анализирует документы PEP, сравнивает статусы и подсчитывает количество документов для каждого статуса.

Итоговая статистика формируется на основе фактических статусов, полученных со страниц отдельных PEP.

## Форматы вывода

Приложение поддерживает три способа представления результатов.

### Обычный вывод

Если не указывать параметр `-o`, результаты выводятся в терминал построчно:

```bash
python -m src.main pep
```

### Красивый вывод в терминал — `pretty`

Для вывода таблицы с помощью PrettyTable:

```bash
python -m src.main pep -o pretty
```

Пример результата:

```text
+-------------+------------+
| Статус      | Количество |
+-------------+------------+
| Active      | 38         |
| Accepted    | 11         |
| Final       | 375        |
| Provisional | 1          |
| Draft       | 57         |
| Superseded  | 25         |
| Deferred    | 35         |
| Withdrawn   | 74         |
| Rejected    | 131        |
| April Fool! | 1          |
| Total       | 748        |
+-------------+------------+
```

### Сохранение в CSV — `file`

```bash
python -m src.main pep -o file
```

Имя файла содержит режим работы и дату создания.

CSV-файл автоматически создаётся в директории:

```text
src/results/
```

## Кэширование

Полученные HTTP-ответы сохраняются в кэше, поэтому при повторном запуске парсера не требуется заново скачивать каждую страницу, пока ответ доступен в кэше.

Для очистки кэша перед запуском используется флаг `-c` или `--clear-cache`:

```bash
python -m src.main pep -c -o pretty
```

## Логирование

Сообщения отображаются в терминале и записываются в файл:

```text
src/logs/parser.log
```

Логируются запуск и завершение приложения, аргументы командной строки, ошибки HTTP-запросов, а также обнаруженные несовпадения статусов PEP.

Пример записи о несовпадении:

```text
19.11.2026 22:48:30 - [INFO] - https://peps.python.org/pep-0401/
Статус в карточке: April Fool!
Ожидаемые статусы: ['Rejected']
```

Для ограничения размера логов используется `RotatingFileHandler` с ротацией файлов.
